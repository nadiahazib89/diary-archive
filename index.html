Claude API key

This tool calls Claude directly from your browser to transcribe each page, so it needs your own API key. This is separate from any claude.ai subscription — it's billed pay-as-you-go, and this particular workload (~2,000 pages of handwriting) typically costs somewhere in the low tens of dollars total, though actual cost depends on page density. Get a key at platform.claude.com under Settings → API keys.

The key is stored only in this browser's local storage, never sent anywhere except directly to Anthropic's API. Because this page is publicly hosted, avoid sharing your repo/page as a "try it live" link with others — anyone using this tool in their own browser needs to enter their own key; it never gets baked into the page's source code.
